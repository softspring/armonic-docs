# Armonic flavours

## Armonic standalone {#armonic-standalone}

Armonic standalone version is a fully functional project that can be used as a base for your project. 

It includes all the bundles and components needed to start a project.

## Armonic for existing projects {#armonic-existing}

Armonic can be integrated into an existing Symfony project, just installing the bundles and components you need.

## Armonic for Sylius {#armonic-sylius}

Armonic can be integrated into a Sylius project, just installing the bundles and components you need.
