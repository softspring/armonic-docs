# Armonic documentation {#armonic-documentation}

Armonic adds content management to Symfony applications. Developers define the layouts and modules. Editors use them to build, preview, and publish pages.

## Find your starting point {#find-your-starting-point}

- **Exploring Armonic?** Read [Why Armonic?](../introduction/why-armonic.md) to see how it fits your project.
- **Ready to install?** Start with [Getting started](../getting-started/overview.md) and choose an installation guide.
- **Setting up a website?** Use [Armonic configuration](../configuration/overview.md) to define sites, layouts, and editable content.
- **Working in the admin area?** Open the [User manual](../user-manual/overview.md) for editing and publishing tasks.
- **Adding features to an application?** Browse the [Bundles](../bundles/overview.md) and [Components](../components/overview.md) guides.

## Try a complete example {#try-a-complete-example}

Once your application is installed, [build and publish a small website](../user-manual/build-a-small-website.md). The walkthrough combines pages, modules, a shared menu, and a reusable block.
