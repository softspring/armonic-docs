# User manual {#user-manual}

Use these guides to work in the Armonic admin area. The available page types, modules, and fields depend on how your application is configured.

## Create and publish a page {#create-and-publish-a-page}

1. [Create a new page](../user-manual/create-a-new-page.md) and set its name, route, and languages.
2. [Add modules or blocks](../user-manual/adding-modules-or-blocks.md) to write and arrange its content.
3. [Preview and publish](../user-manual/preview-and-publish-a-page.md) when the page is ready.

## Manage shared content {#manage-shared-content}

- [Create a block](../user-manual/create-a-new-block.md) for content you want to reuse.
- [Create a menu](../user-manual/create-a-new-menu.md) to organise navigation links.
- [Create media](../user-manual/create-a-new-media.md) to add files to the media library.
- [Create routes](../user-manual/create-routes.md) to connect URL paths to content or redirects.

## Follow a complete walkthrough {#follow-a-complete-walkthrough}

[Build and publish a small website](../user-manual/build-a-small-website.md) combines configuration and editing in one example. It includes developer setup, so use it with your developer if you only manage content.
