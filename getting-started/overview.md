# Getting started {#getting-started}

Start by checking the [requirements](../getting-started/requirements.md), then choose the guide that matches your project. Use [Configure MySQL or PostgreSQL](../getting-started/configure-database.md) for the database service and connection settings.

## Choose an installation {#choose-an-installation}

- **Starting from a Symfony application:** [Install Armonic in a new Symfony project](../getting-started/install-new-symfony-project.md).
- **Adding a CMS to your application:** [Install Armonic in an existing Symfony project](../getting-started/install-existing-symfony-project.md).
- **Using a base project with Armonic included:** [Install the standalone edition](../standalone/install-armonic-standalone.md).
- **Adding content pages to a shop:** [Install Armonic in a Sylius project](../getting-started/install-sylius-project.md).

## After installation {#after-installation}

Use [Armonic configuration](../configuration/overview.md) to prepare your sites and content structure. Then follow [Build and publish a small website](../user-manual/build-a-small-website.md) to put those pieces together.

If your application is already configured and you only need to edit content, go to the [User manual](../user-manual/overview.md).
