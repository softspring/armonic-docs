# Google Cloud Integration Bundle {#google-cloud-integration-bundle}

This bundle provides Google Cloud integrations for Symfony projects.

Its documented use cases are logging, error reporting, and tracing.

## Installation {#installation}

```bash
composer require softspring/google-cloud-integration-bundle:^6.0
```

## What It Provides {#what-it-provides}

- Google Cloud logging integration
- Google Cloud error reporting integration
- Google Cloud trace integration
- Symfony dependency injection and event listener wiring
