# Time Ago Bundle {#time-ago-bundle}

This bundle provides a Twig extension to render human-readable time differences.

It is translation-aware and designed for Symfony projects.

## Installation {#installation}

```bash
composer require softspring/time-ago-bundle:^6.0
```

## What It Provides {#what-it-provides}

- Twig helpers for relative time rendering
- translation-aware output
